## Fundo floral

A primeira versão do fundo floral foi aprovada pelo usuário nesta conversa.

- Arquivo: `fundo-floral-v1.png`.
- Fundo marfim com flores discretas nos cantos inferiores e área central livre.
- Brief completo: `fundo-floral-v1.prompt.txt`.
- Geração: ferramenta integrada ImageGen, usando o logo aprovado e a pintura como referências.

Logo e fundo são as referências visuais aprovadas para a primeira versão do site. Os arquivos estão em raster; as versões para entrega web serão dimensionadas e otimizadas na implementação.
